# 🏠 집정리 플래너

휴대폰에서 쓰는 집정리 계획 웹앱(PWA)입니다.

## 기능
- **기본 정리 순서**: 준비 → 현관 → 욕실 → 주방 → 거실 → 옷장/침실 → 서류/책 → 추억의 물건 → 유지 습관.
  단계마다 체크리스트, 예상 시간, 팁이 있고 진행률이 표시됩니다. 단계·항목 추가/삭제/순서 변경 가능.
- **사진 분석**: 공간 사진을 찍어 올리면 Claude가 현재 상태, 정리 순서, 비울 후보, 수납 아이디어, 유지 팁을 알려줍니다.
  결과를 버튼 하나로 내 정리 순서에 추가할 수 있습니다.
- 모든 데이터는 이 기기(브라우저)에만 저장됩니다. 화면 파일은 오프라인에서도 열립니다.

## 사용 준비
1. [console.anthropic.com](https://console.anthropic.com/settings/keys)에서 API 키를 발급받습니다. (사진 분석 1회마다 소액의 사용료가 듭니다)
2. 앱의 **설정** 탭에 키를 입력하고 저장합니다.

> API 키는 브라우저에서 직접 Anthropic API로 전송됩니다. **본인 기기에서 개인용으로만** 쓰고, 키를 저장소에 올리거나 남과 공유하지 마세요.

## 실행 / 배포
- 내 컴퓨터: `cd app && python3 -m http.server 8000` → http://localhost:8000
- 휴대폰에서 쓰기: GitHub Pages 등 HTTPS 호스팅에 `app/` 폴더를 올린 뒤, 휴대폰 브라우저에서 열고 **홈 화면에 추가**.
