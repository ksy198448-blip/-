# 쉐도잉 스튜디오

유튜브 쇼츠(또는 아무 유튜브 영상)로 매일 영어 쉐도잉을 연습하는 개인용 웹 앱입니다.
서버나 빌드 과정 없이 정적 파일만으로 동작합니다.

## 기능

- 문장 단위 스크립트 + 한국어 번역 + 주요 단어 정리
- 문장별 "▶ 원어민 발음" 재생 (유튜브 영상에서 해당 구간만 재생), 3회 반복 재생
- 0.5x / 0.75x / 1x 재생 속도 조절
- 🎙 내 발음 녹음 후 다시 듣기 (브라우저에만 저장, 서버 전송 없음)
- 발음 분석: 브라우저 음성 인식(Web Speech API)으로 내 발음을 텍스트로 바꿔 원문과 단어 단위로 비교, 일치도(%) 채점
- 매일 학습 스트릭(연속 일수) 기록

## 실행 방법

파일을 그냥 더블클릭해서 열어도 대부분 동작하지만, 마이크 녹음 기능과 저장 기능이
브라우저별로 `file://` 환경에서 불안정할 수 있어 **로컬 서버로 열기를 권장**합니다.

```bash
cd shadowing-app
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

또는 GitHub Pages 등으로 배포해서 휴대폰 브라우저에서도 매일 접속해 쓸 수 있습니다.

## 영상 추가하는 방법

1. 왼쪽 사이드바에서 **+ 새 영상 추가** 클릭
2. 유튜브 쇼츠 링크(또는 영상 ID) 입력
   - 예: `https://www.youtube.com/shorts/XXXXXXXXXXX`
3. 스크립트 입력란에 한 줄에 문장 하나씩, `영어 문장 | 한국어 번역` 형식으로 입력
   - 번역이 없으면 `|` 없이 영어만 입력해도 됩니다.
4. 주요 단어는 `단어 - 뜻` 형식으로 한 줄에 하나씩 입력 (선택 사항)
5. 저장하면 레슨이 생성됩니다.

### 재생 구간(타임스탬프) 설정하기 — "구간 설정 모드"

유튜브 자막에서 문장별 정확한 시작/끝 시간을 앱이 자동으로 알아낼 수는 없어서,
직접 탭 한 번으로 맞추는 방식을 사용합니다.

1. 레슨 화면에서 **⏱ 구간 설정 모드** 클릭
2. **▶ 재생하고 탭 시작** 클릭 → 영상이 처음부터 재생됩니다
3. 화면에 표시되는 문장이 실제로 시작되는 순간마다 **다음 문장 시작(Space)** 버튼을 클릭하거나 스페이스바를 누릅니다
4. 마지막 문장까지 탭하면 자동으로 각 문장의 시작/끝 시간이 저장됩니다
5. 이후에는 문장 옆의 "▶ 원어민 발음" 버튼으로 정확히 그 구간만 재생됩니다

한 번 설정해두면 계속 저장되어 있으니, 영상마다 한 번씩만 하면 됩니다.

## 발음 분석에 대한 참고

- 브라우저 음성 인식(Web Speech API)은 **Chrome 계열 브라우저 + 인터넷 연결 + 마이크 권한**이 필요합니다. Firefox/Safari는 지원이 불안정하거나 되지 않을 수 있습니다.
- 점수는 정확한 음성학적(발음기호) 분석이 아니라, "내가 말한 내용을 인식한 텍스트"와 "원문"을 단어 단위로 비교한 근사치입니다. 발음이 좋아도 인식이 실패하면 점수가 낮게 나올 수 있으니 참고용으로만 활용하세요.
- 녹음 파일은 서버로 전송되지 않고 브라우저(IndexedDB)에만 저장됩니다. 브라우저 저장공간을 지우면 함께 삭제됩니다.

## 데이터 저장 위치

- 레슨/스크립트/진도/스트릭: `localStorage`
- 내 녹음 파일: `IndexedDB`
- 모두 브라우저(기기)별로 저장되며 서버로 전송되지 않습니다. 다른 기기에서 이어서 쓰려면 별도 동기화 기능이 없으니 참고하세요.
